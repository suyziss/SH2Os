# Suyziss — Developer Landing

Personal portfolio website for [@suyziss](https://github.com/suyziss).

🌐 **Live site:** https://suyziss.github.io/SH2Os/

## Features
- Responsive dark portfolio layout
- Russian / English language switch
- Live GitHub profile stats
- Featured repositories loaded from the GitHub public API
- No build tools or dependencies required

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save and wait for GitHub Pages to publish the site.

## Run locally
Open `index.html` in any modern browser. For a local HTTP server:
```bash
python -m http.server 8000
```
Then open http://localhost:8000.

Made with HTML, CSS and JavaScript.
